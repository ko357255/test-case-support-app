# テストケースドキュメント作成支援Webアプリ

## 概要

本アプリは、テストケースのドキュメント作成を効率化するためのWebアプリケーションです。
テストケース作成における入力作業や画像管理の手間を軽減することを目的として開発しました。
フォーム上で直感的にテストケースを入力でき、画像の添付・管理を簡単に行うことができます。

---

## 主な機能

- プロジェクトの管理機能
- テストケースの作成機能
- 画像添付機能
- リアルタイムでの共同編集機能
- ログイン機能

---

## 使用技術

### フロントエンド

- React
- Next.js
- Tailwind CSS

### バックエンド

- Cloud Firestore
- Cloud Storage for Firebase
- Firebase Realtime Database
- Firebase Authentication
- NextAuth.js

## セットアップ方法

```bash
git clone <repository-url>
cd <project-name>
npm install
npm run dev
```

※ Firebaseの設定は各自で環境変数に設定してください。
